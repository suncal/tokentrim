What no tool can cut

Claude Code's own system prompt and tool list cost 40–60k tokens on every call, and a fresh desktop chat starts near 77k. Those are fixed by Claude Code, so a short session saves little and nobody can honestly promise 90% across all your work.

Billed cost and limit burn fall less than tokens, about 55–70%, because cached re-reads are cheap per token and output isn't touched.

Get your own number

The replay runs locally on your own transcripts before you install anything. Nothing leaves your machine.

git clone https://github.com/suncal/tokentrim && cd tokentrim
bin/tokentrim replay
