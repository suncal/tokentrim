Security & privacy

It sees every tool call. So it's built to be boring and safe.

tokentrim runs as Claude Code hooks. Here is exactly what stays on your machine, what leaves it, and how you stay in control.

Never leaves your machine

  • Prompts, code and transcripts. Read locally from ~/.claude to measure usage. Never uploaded.
  • Full tool output. Trimmed for Claude, with the complete copy kept on your disk.
  • Your settings. Backed up before install and restored on uninstall.
  • No network calls by default. Standard-library Python. The only exception is opt-in: live --deploy sends totals to your own Cloudflare page.

Sent only if you choose Pro

  • License check: your key and a machine label, to Polar.
  • Hosted dashboard: usage totals and project folder names. Never prompts or code.
  • Slack: opt-in, weekly totals only, with a test message first.
  • Payment: handled entirely by Polar. We never see your card.

Fails open

If a hook errors, Claude Code carries on as if tokentrim weren't there.

Instant kill switch

"enabled": false in its config turns every hook off at once.

Tested on every change

The full suite runs in CI on macOS and Linux, Python 3.9, 3.11 and 3.13.

Open to audit

Apache-2.0 source. Report issues privately; you get a reply within 3 days.

The honest numbers

Why we don't promise 90%.

Claude Code's own system prompt and tool list cost 40–60k tokens on every step, and no setting removes them. Anyone promising 90% across all your work is measuring one noisy command, or not measuring.

So tokentrim shows its working: a replay of real transcripts, every estimate labelled, and three strength settings with the trade-off spelled out.

See every benchmark Read the full method
  • The trade-off is realSummarising sooner means Claude forgets detail sooner. The default, strong, behaves close to Claude Code's old 200k window. Balanced is gentler; max is cheapest.
  • Cost drops less than tokensRe-reads are cheap per token and output isn't touched, so billed cost and limit burn fall about 55–70%, not 75%.
  • Your number will differShort sessions re-read little, so they save little. That's why the replay comes first, before you install anything.
  • Not affiliated with Anthropictokentrim uses Claude Code's public hooks and settings. It doesn't patch Claude Code or touch your account.

Questions

Before you install

Something not covered? Email support@boltak.com or ask in Discussions.

Does anything leave my machine?

No. The free tool reads transcripts Claude Code already stores locally and never sends them anywhere. Pro's license check sends only your key and a machine label. The hosted Pro dashboard receives totals and project folder names only, never prompts or code. Slack posting is opt-in and sends weekly totals only.

Plugin or full install: which should I use?

The plugin is one command and adds the hooks plus /tokentrim:replay, /tokentrim:dashboard and /tokentrim:share. A plugin can't set the compaction window, which is where most of the saving comes from, so also run tokentrim install from a clone if you want it. Having both is safe: the plugin's hooks stand down while the full install's hooks are active, so nothing runs twice.

Can it pick the best model for each message?

Not per message: Claude Code has no switch for that. Smart model uses Claude Code's own opusplan (Opus plans, Sonnet does the work), and pairs well with cheaper sub-agents, lower effort and the model advisor. Model changes apply to new sessions; /model in a session still wins.

I'm on a Pro or Max plan, not paying per token. Does this help?

Yes, and it's the main reason most people use it. Plan limits are spent on the same tokens, so re-reading less means hitting the 5-hour and weekly limits later. On the author's usage, limits lasted 4.0× longer.

Will Claude forget things?

It summarises earlier, so very old detail in a long conversation gets condensed sooner. The default profile behaves close to how Claude Code worked with a 200k window. If you notice it, switch to balanced with one command.

How do I undo it?

tokentrim uninstall removes exactly what install added. Your settings were backed up before install, your own hooks are left alone, and one config flag turns every hook off instantly. Remove the plugin with claude plugin uninstall tokentrim@tokentrim.

What do I need?

Claude Code and Python 3.9 or newer. No packages to install. It's tested on macOS and Linux. The Pro Monday digest schedules itself on macOS; elsewhere you can run tokentrim digest from your own scheduler.
