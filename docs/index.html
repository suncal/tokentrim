The hidden cost

Your limit isn't spent on new work. It's spent re-reading old work.

An agent loop re-sends the entire conversation on every step. A long session carrying 400k tokens pays for those 400k again on step 301. About 97% of the tokens Claude Code bills are this re-reading.

The honest numbers

Why we don't promise 90%.

Claude Code's own system prompt and tool list cost 40–60k tokens on every step, and no setting removes them. Anyone promising 90% across all your work is measuring one noisy command, or not measuring.

So tokentrim shows its working: a replay of real transcripts, every estimate labelled, and three strength settings with the trade-off spelled out.

Read the full method
  • The trade-off is realSummarising sooner means Claude forgets detail sooner. The default, strong, behaves close to Claude Code's old 200k window. Balanced is gentler; max is cheapest.
  • Cost drops less than tokensRe-reads are cheap per token and output isn't touched, so billed cost and limit burn fall about 55–70%, not 74%.
  • Fails open, alwaysIf a hook errors, Claude Code carries on as if tokentrim weren't there. One setting switches every hook off instantly.
  • Local by designPython standard library only. Your prompts, code and transcripts never leave your machine.

Questions

Before you install

Does anything leave my machine?

No. The free tool reads transcripts Claude Code already stores locally and never sends them anywhere. Pro's license check sends only your key and a machine label. Slack posting is opt-in and sends weekly totals only, never prompts, code or conversation titles.

I'm on a Pro or Max plan, not paying per token. Does this help?

Yes, and it's the main reason most people use it. Plan limits are spent on the same tokens, so re-reading less means hitting the 5-hour and weekly limits later. On the author's usage, limits lasted 3.9× longer.

Will Claude forget things?

It summarises earlier, so very old detail in a long conversation gets condensed sooner. The default profile behaves close to how Claude Code worked with a 200k window. If you notice it, switch to balanced with one command.

How do I undo it?

tokentrim uninstall removes exactly what install added. Your settings were backed up before install, your own hooks are left alone, and one config flag turns every hook off instantly.

What do I need?

Claude Code and Python 3.9 or newer. No packages to install. The Pro Monday digest schedules itself on macOS; elsewhere you can run tokentrim digest from your own scheduler.

How does the lifetime deal work?

$49 once for the first 500 buyers, with all future Pro updates. After that, Pro is $9 a month. Either way you get a license key by email that works on up to 3 machines; move it with tokentrim pro deactivate.
