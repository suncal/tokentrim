Claude Code Token Dashboard

TokenTrim is a free, local toolkit that helps extend Claude Code usage limits by optimizing tool output and file reading. It provides a dashboard to track token spend per session, making it easier to manage Claude Code usage.

What you get

Why tokentrim

TokenTrim is designed for developers and CTOs at 10-200 person US software companies who frequently hit Claude Code limits. By using TokenTrim, users can make their Claude Code usage limits last longer and reduce token waste.
