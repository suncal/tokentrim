# Code of conduct

tokentrim follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique ideas rather than people, and keep it welcoming for newcomers. Harassment of any kind isn't tolerated.

Report problems privately through [GitHub security advisories](https://github.com/suncal/tokentrim/security/advisories/new) or by contacting the maintainer, [@suncal](https://github.com/suncal). Reports are kept confidential.
